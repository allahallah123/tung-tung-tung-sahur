# SCP Foundation C++ Website

A fan-made SCP Foundation anomaly console with a unique redacted terminal UI, animated containment glyph, and dossier cards for several SCP-inspired subjects.

## Run it with C++

Build and start the tiny socket-based web server:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o scp_console
./scp_console 8080
```

Then open <http://localhost:8080>.

## Static preview

`index.html` contains the same interface for quick static hosting or browser preview.
