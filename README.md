# tung-tung-tung-sahur

Mini game quiz code dạng ABCD bằng HTML/CSS/JS.

## Tính năng
- Có các câu hỏi lựa chọn A/B/C/D.
- Chọn đúng: đáp án được tô màu xanh.
- Chọn sai: đáp án chọn bị tô đỏ và tự động hiện đáp án đúng màu xanh.
- Có điểm số và chuyển câu tiếp theo.

## Chạy dự án
Bạn có thể mở trực tiếp `index.html` hoặc chạy server tĩnh:

```bash
python3 -m http.server 8000
```

Sau đó truy cập `http://localhost:8000`.
